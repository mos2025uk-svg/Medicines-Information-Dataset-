# TCF Vancouver Monitor 🇨🇦

این اپ هر ۳۰ دقیقه صفحه‌ی ثبت‌نام آزمون **TCF Canada** در مراکز ونکوور را چک می‌کند و به‌محض اینکه ثبت‌نام باز شود (یا صفحه تغییر کند) یک **نوتیفیکیشن فوری روی گوشی** برایتان می‌فرستد.

مراکز پیش‌فرض (در `config.yaml`):
- **Alliance Française Vancouver** — 6161 Cambie St
- **Ashton Testing Services** — 1190 Melville St

## چطور کار می‌کند
1. GitHub Actions هر ۳۰ دقیقه `monitor.py` را اجرا می‌کند (رایگان، بدون نیاز به روشن بودن کامپیوتر).
2. متن صفحه‌ی هر مرکز خوانده می‌شود و دنبال کلمات کلیدی می‌گردد:
   - اگر کلمه‌ای مثل `register now` / `book now` پیدا شود ← **باز است** 🟢
   - اگر پیام «پر است» (`sold out`, `complet`, …) قبلاً بود و حالا ناپدید شده ← **باز است** 🟢
   - اگر صفحه هر تغییری کرد ← هشدار «صفحه تغییر کرد» 🔔
3. وضعیت در `state.json` ذخیره می‌شود تا برای یک اتفاق چند بار هشدار نگیرید.

## راه‌اندازی (حدود ۵ دقیقه)

### ۱) نوتیفیکیشن روی گوشی — ntfy (ساده‌ترین)
1. اپ **ntfy** را از App Store / Google Play نصب کنید.
2. یک اسم موضوع (topic) یکتا و سخت انتخاب کنید، مثلاً `tcf-van-8f3k29x` و در اپ Subscribe کنید.
   ⚠️ هر کسی اسم topic را بداند پیام‌ها را می‌بیند، پس اسم حدس‌زدنی نگذارید.

### ۲) (اختیاری) تلگرام
1. در تلگرام با `@BotFather` یک بات بسازید و **توکن** را بگیرید.
2. یک پیام به بات بدهید، بعد `https://api.telegram.org/bot<TOKEN>/getUpdates` را باز کنید و `chat.id` را بردارید.

### ۳) تنظیم Secrets در GitHub
در ریپو: **Settings → Secrets and variables → Actions → New repository secret**
| نام | مقدار |
|---|---|
| `NTFY_TOPIC` | اسم topic شما |
| `TELEGRAM_BOT_TOKEN` | (اختیاری) توکن بات |
| `TELEGRAM_CHAT_ID` | (اختیاری) chat id |

### ۴) فعال‌سازی
- فایل‌ها باید روی **branch اصلی (main)** باشند؛ زمان‌بندی GitHub فقط روی branch پیش‌فرض اجرا می‌شود.
- در تب **Actions** گردش‌کار `TCF Vancouver monitor` را باز کنید و **Run workflow** بزنید تا اولین اجرا انجام شود.

### ۵) تست نوتیفیکیشن (روی کامپیوتر خودتان)
```bash
cd tcf-monitor
pip install -r requirements.txt
NTFY_TOPIC=tcf-van-8f3k29x python monitor.py --test-notify
```

## اجرای محلی به‌جای GitHub
```bash
NTFY_TOPIC=tcf-van-8f3k29x python monitor.py --loop 1800   # هر ۳۰ دقیقه
```

## ⚠️ نکات مهم
- **کلمات کلیدی را تنظیم کنید:** وقتی ثبت‌نام بسته است، صفحه‌ی هر مرکز را باز کنید و جمله‌ی دقیق «پر است / جلسه‌ای نیست» را در `closed_keywords` در `config.yaml` بگذارید. این مهم‌ترین قدم برای دقیق بودن هشدارهاست.
- اگر مرکز ثبت‌نام را در سایت دیگری انجام می‌دهد (مثلاً یک صفحه‌ی رزرو جدا)، آدرس همان صفحه را در `url` بگذارید.
- صفحاتی که نیاز به **لاگین** دارند یا محتوایشان فقط با JavaScript لود می‌شود با این روش دیده نمی‌شوند؛ در آن صورت `alert_on_change: true` همچنان تغییرات صفحه‌ی عمومی را گزارش می‌دهد.
- طبق تجربه‌ی داوطلبان، تاریخ‌ها معمولاً **اولین دوشنبه‌ی ماه حدود ظهر** برای ماه بعد باز می‌شوند و در چند دقیقه پر می‌شوند — آن روزها خودتان هم آماده باشید.
- اگر سایتی سه بار پشت‌سرهم در دسترس نباشد، یک هشدار «cannot reach» دریافت می‌کنید.
- GitHub ممکن است اجرای زمان‌بندی‌شده را چند دقیقه دیر کند، و اگر ریپو ۶۰ روز هیچ فعالیتی نداشته باشد آن را غیرفعال می‌کند (کامیت‌های خودکار state.json جلوی این را می‌گیرد).

## مرکز جدید اضافه کنید
یک آیتم دیگر به لیست `centres` در `config.yaml` اضافه کنید (`name`, `url`, `selector`, `open_keywords`, `closed_keywords`, `alert_on_change`).
